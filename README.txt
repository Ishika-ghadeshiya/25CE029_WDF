StudentHub WDF Practical 3 - Based on Practicals 1 and 2

This package continues the StudentHub pages from Practical 2 and keeps the
existing capitalized page filenames:
Home.html, About.html, Register.html, Dashboard.html, Events.html.

The stylesheet is in css/style.css.

Run:
1. Copy these files into your existing 25CE029_WDF project.
2. Keep the css folder beside the HTML files.
3. Open Home.html in a browser or use VS Code Live Server.
4. Test links and responsive layouts at mobile, tablet, and desktop widths.

Flexbox is used for navigation and button groups. CSS Grid is used for cards,
the home hero, the registration form, and dashboard statistics. The stylesheet
starts with mobile styles and adds media queries at 600px and 900px.

The registration form is only a front-end demonstration and is not connected
to a database.
